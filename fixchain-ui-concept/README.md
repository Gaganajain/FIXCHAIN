# FIXCHAIN UI Concept

Independent premium frontend concept for FIXCHAIN — an AI-powered payment incident intelligence platform.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS
- Shadcn UI primitives (Radix UI)
- Lucide React (icons)
- Framer Motion (animations)
- Recharts (charts)
- React Flow (agent workflow visualization)
- TanStack Table (data tables)
- Sonner (toasts)

## Get Started

```bash
cd fixchain-ui-concept
npm install
npm run dev
```

The app runs on `http://localhost:5174`.

## Screens

1. Mission Control Overview
2. Customer Ticket Center
3. Incident Intelligence Center
4. AI Agent Command Center
5. Resolution & Approval Center
6. Engineering Remediation
7. Knowledge & Learning Center
8. Simulation Lab
9. Historical Analytics

All data is mock/local. No backend is connected.
