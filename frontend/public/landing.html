The problem

A customer paid. The merchant’s code said “failed”.

01

Customer pays

The bank is still confirming, so the gateway reports PENDING.

02

Code misreads it

A small bug in the merchant’s callback handler treats PENDING as FAILED.

03

Money arrives anyway

The bank confirms, but the order is already final, so the update is ignored.

04

Refunds and tickets

The customer is charged with no order, and the gateway gets the blame.

The gateway did nothing wrong. The bug lives in merchant integration code, written thousands of different ways, and today it’s found by customers and fixed by support tickets.

Safety

Safe enough for a payments company.

AI never decides a payment

Order states change only through signed gateway callbacks. No money moves.

Independent verifier

A locked test suite the AI can’t read or edit, hash-checked before every run.

Named human approval

Nothing goes live without a reviewer’s name and token, kept in the audit trail.

Knows what isn’t a bug

Forged or mis-signed callbacks are flagged as external incidents, never “fixed”.
